# DShop M0 字段契约（41 表实现侧定案）

> `docs/05` 只给出了字段**语义**，未给出 `CREATE TABLE`、字段类型、`NOT NULL`/`DEFAULT`/`CHECK`/`ON DELETE`。
> 本文件是**实现侧定案**，作为 `packages/db`（Drizzle schema + D1 迁移）、`data/seed-cs/`、`apps/api` 仓库层的**唯一列名基准**。
> 本文件覆盖 `docs/M0-实施简报.md` §8「文档未定义项」第 1 项。文档有冲突时以 `docs/` 原文为准，并回改本文件。

---

## 0. 全局约定（`docs/05` §5.3）

| 项 | 约定 |
| --- | --- |
| 主键 | `id TEXT PRIMARY KEY`，**ULID 26 位**（`@dshop/shared` 的 `newId()`） |
| 金额 | `INTEGER`，单位**分**，列名后缀 `_amount`（`pay_amount` 除外，沿用文档列名） |
| 比例 | `INTEGER`，**万分比**，列名后缀 `_bp` |
| 时间 | `TEXT`，**ISO-8601 UTC**（`YYYY-MM-DDTHH:mm:ss.sssZ`） |
| 布尔 | `INTEGER`，`0`/`1`，`NOT NULL DEFAULT 0`，列名用 `is_*` 或文档原名（`settled`/`selected`/`searchable`/`supports_pickup`/`totp_enabled`） |
| JSON | `TEXT`，`NOT NULL DEFAULT '{}'` 或 `'[]'`，应用层 `JSON.parse`；D1/SQLite 无原生 jsonb |
| 删除 | **不做物理删除**，用 `status` 枚举软删除 |
| 外键 | **不声明 SQL 级 `FOREIGN KEY`**（D1 外键约束影响批量写与迁移），由应用层保证；索引照建 |
| 命名 | SQL `snake_case`；Drizzle 对象属性 `camelCase`；JSON 响应 `camelCase` |

**通用列**（除 `settings` 等纯 KV 表外，所有业务表都有）：

- `created_at TEXT NOT NULL`
- `updated_at TEXT NOT NULL`

以下逐表列出时**不再重复这两列**（标注 `+created/updated` 的表即含）。
